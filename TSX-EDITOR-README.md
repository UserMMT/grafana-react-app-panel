# TSX Editor & Renderer - Complete Guide\n\n## Overview\n\nThe **generic Grafana panel plugin** now includes a built-in TSX/JSX code editor and renderer. This allows you to:\n\n✅ Write/edit React components directly in Grafana  \n✅ Upload .tsx/.jsx files  \n✅ Live preview rendered components  \n✅ Store code in panel configuration  \n✅ No build process needed - code executed at runtime  \n\n---\n\n## Architecture\n\n```\n┌─────────────────────────────────────────┐\n│  Grafana Panel preview tabs\n- Code saving to panel options\n- Component rendering\n- UI state\n\n### 2. **CodeEditor** (`src/components/CodeEditor.tsx`)\n\nCode editing interface:\n- Syntax highlighting\n- File upload support\n- Validation\n- Line numbers (in textarea)\n\n### 3. **DynamicComponentRenderer** (`src/components/DynamicComponentRenderer.tsx`)\n\nExecutes and renders TSX code:\n- Runtime code compilation\n- Error handling\n- External imports injection\n- Props passing\n\n---\n\n## Usage Workflow\n\n### Step 1: Create Grafana Panel\n\n1. Open any Grafana dashboard\n2. Click **Add panel**\n3. Select **React App Panel** plugin\n4. Click **Edit**\n\n### Step 2: Write or Upload Component\n\n#### Option A: Write Inline\n\nGo to **Edit Code** tab and write your component:\n\n```tsx\nexport default function MyApp() {\n  const [count, setCount] = React.useState(0);\n  \n  return (\n    <div style={{ padding: '20px' }}>\n      <h1>Hello Grafana!</h1>\n      <p>Count: {count}</p>\n      <button onClick={() => setCount(count + 1)}>\n        Increment\n      </button>\n    </div>\n  );\n}\n```\n\n#### Option B: Upload File\n\n1. Click **📁 Upload File**\n2. Select your .tsx/.jsx file\n3. Code is automatically loaded\n\n### Step 3: Preview Component\n\nSwitch to **Preview** tab to see your component rendered in real-time.\n\n### Step 4: Save Code\n\nClick **💾 Save Code** to persist to panel options.\n\n---\n\n## Code Requirements\n\nYour component must:\n\n1. **Export a default React component**\n   ```tsx\n   export default function MyComponent() {\n     return <div>...</div>;\n   }\n   ```\n\n2. **Have a single root element**\n   ```tsx\n   // ❌ Wrong - multiple root elements\n   return (\n     <div>A</div>\n     <div>B</div>\n   );\n   \n   // ✅ Correct\n   return (\n     <div>\n       <div>A</div>\n       <div>B</div>\n     </div>\n   );\n   ```\n\n3. **Use only available imports**\n   - `React` is always available\n   - Other imports must be pre-configured\n\n---\n\n## Examples\n\n### Example 1: Simple Counter\n\n```tsx\nexport default function Counter() {\n  const [count, setCount] = React.useState(0);\n\n  return (\n    <div style={{ padding: '20px', fontFamily: 'sans-serif' }}>\n      <h1>Counter</h1>\n      <p>Count: <strong>{count}</strong></p>\n      <button onClick={() => setCount(count + 1)}>+</button>\n      <button onClick={() => setCount(count - 1)}>-</button>\n    </div>\n  );\n}\n```\n\n### Example 2: Multi-Tab App\n\n```tsx\nexport default function TabsApp() {\n  const [activeTab, setActiveTab] = React.useState('home');\n\n  return (\n    <div style={{ padding: '20px' }}>\n      <div style={{ display: 'flex', gap: '8px', marginBottom: '16px' }}>\n        <button\n          onClick={() => setActiveTab('home')}\n          style={{\n            padding: '8px 16px',\n            backgroundColor: activeTab === 'home' ? \"No default export found\"\n\n**Cause:** Component doesn't export default\n\n**Fix:**\n```tsx\n// ❌ Wrong\nfunction MyApp() { /* ... */ }\n\n// ✅ Correct\nexport default function MyApp() { /* ... */ }\n```\n\n### \"Cannot read property 'useState' of undefined\"\n\n**Cause:** Using `useState` instead of `React.useState`\n\n**Fix:**\n```tsx\n// ❌ Wrong\nimport { useState } from 'react';\nconst [count, setCount] = useState(0);\n\n// ✅ Correct (React is global)\nconst [count, setCount] = React.useState(0);\n```\n\n### Component doesn't render\n\n**Cause:** Multiple root elements\n\n**Fix:** Wrap all children in a single parent:\n```tsx\n// ❌ Wrong\nreturn (\n  <div>A</div>\n  <div>B</div>\n);\n\n// ✅ Correct\nreturn (\n  <>\n    <div>A</div>\n    <div>B</div>\n  </>\n);\n```\n\n### File upload doesn't work\n\n**Cause:** File is too large or wrong format\n\n**Fix:** Use .tsx or .jsx files, max 1MB\n\n---\n\n## Performance Tips\n\n1. **Memoize expensive computations**\n   ```tsx\n   const expensiveValue = React.useMemo(() => {\n     return computeExpensiveValue(data);\n   }, [data]);\n   ```\n\n2. **Use useCallback for event handlers**\n   ```tsx\n   const handleClick = React.useCallback(() => {\n     // ...\n   }, [dependencies]);\n   ```\n\n3. **Lazy load heavy components**\n   ```tsx\n   const HeavyComponent = React.lazy(() => import('./Heavy'));\n   // Will fail in editor - use inline instead\n   ```\n\n---\n\n## Next Steps\n\n1. ✅ Build and deploy the plugin\n2. ✅ Create a panel in your dashboard\n3. ✅ Write a simple component (counter example)\n4. ✅ Test
